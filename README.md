<h2 align="center"><a  href="https://nadezhdamartin.github.io/blog-customizer/">Посмотреть на Github Pages</a></h2>

Стек: React, TS, SCSS, Storybook, Webpack

Структура проекта:

- src/ — исходные файлы проекта
- src/components/ — папка с tsx компонентами
- src/constants — папка с константами
- src/ui — папка с ui-компонентами

Важные файлы:

- public/index.html — HTML-файл главной страницы
- src/index.tsx — точка входа приложения
- src/App.tsx — корневой компонент
- src/components/article/Article.tsx — файл с вёрсткой контента
- src/components/article-params-form/ArticleParamsForm.tsx — файл с логикой настроек, которые можно применить к контенту приложения

## Функциональные возможности

- При нажатии на «стрелку» открывается сайдбар с настройками, при повторном нажатии или клике вне сайдбар закрывается.
- При изменении настроек в сайдбаре они не применяются сразу.
- После нажатия на «применить» стили применяются к статье.
- При нажатии «сбросить» настройки в форме сбрасываются на начальные, которые были при открытии страницы, и стили применяются к статье.
- Настройки устанавливаются через CSS-переменные, которые уже есть в стилях и установлены в коде в дефолтные значения.

## Архитектура приложения

### Компонент App

С данного корневого компонента начинается визуальная часть и логика приложения. Использован хук `useState` для хранения состояния изменяемых пользователем стилей к статье. App вкючает в себя два дочерних компонента ArticleParamsForm и Article.

### Компонент ArticleParamsForm

С помощью хука `useState` в функциональный компонент добавлены состояния — форма для редактирования(открыта или закрыта) и изменение стилей текста. Наличие такого состояния позволяет реализовывать динамические компоненты, содержимое которых будет изменяться при взаимодействии с ним пользователя.
Для начального состояния, которое используется только во время начального рендеринга, используем объект `defaultArticleState` из папки 'constants'.
Для изменения состояния формы передаем новый объект, используя spread-оператор, который создаёт изменённую копию исходного объекта.
Для формы используем обработчки событий `handleApply` для передачи установленного состояния в форме и передаем в виде объекта в пропс родительскому компоненту.
Также реализовано закрытие формы при клике на стрелку, нажатии на кнопку Esc на клавиатуре и клике вне области формы.
При клике на кнопку 'сбросить' - состояние формы возвращается к начальному состоянию.

### Компонент Article

Содержит вёрстку статьи приложения.
При первом рендере применены начальные стили к тексту и другим элементам. Далее через CSS-переменные (кастомные свойства), заданные на родительском элементе в теге 'main', изменяются стили статьи.
Article остаётся «глупым» компонентом без логики стилей.
